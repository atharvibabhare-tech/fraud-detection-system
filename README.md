# 🚨 Fraud Detection System

## 📌 Overview

This project is a Machine Learning-based Fraud Detection System developed to identify fraudulent financial transactions using classification algorithms.

The system analyzes transaction-related features and predicts whether a transaction is:
- ✅ Genuine
- 🚨 Fraudulent

The project combines:
- Data Analysis
- Exploratory Data Analysis (EDA)
- Machine Learning
- Model Evaluation
- Streamlit Dashboard Deployment

into a complete end-to-end AI application.

---

# 🎯 Features

- 📊 Fraud Transaction Analysis
- 🤖 Machine Learning Classification Model
- 🚨 Real-Time Fraud Prediction
- 📈 Interactive Visualizations
- 🎨 Streamlit Dashboard
- ⚡ Risk Alert System

---

# 📂 Dataset Information

The dataset contains transaction-related features including:

- Transaction Time
- Transaction Amount
- Encoded Transaction Features (V1–V28)
- Transaction Class

### Target Variable

| Class | Meaning |
|---|---|
| 0 | Genuine Transaction |
| 1 | Fraud Transaction |

---

# 🤖 Machine Learning Model

## Random Forest Classifier

The model was trained to classify fraudulent and genuine transactions.

### Model Performance

- Accuracy: 99.95%
- Precision: 95%
- Recall: 79%
- F1 Score: 86%
